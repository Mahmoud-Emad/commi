How Commi Works

Commi analyzes your Git repository changes and uses Google's Gemini AI to generate meaningful, conventional commit messages that accurately describe your modifications.

1

Analyze Changes

Commi examines your staged or unstaged changes using Git diff

2

AI Processing

Sends the diff to Gemini AI with context about conventional commits

3

Generate Message

Returns a properly formatted commit message following best practices

# Example workflow
$ git add .
$ commi generate
✨ Generated commit message:
feat: add user authentication system

- Implement JWT-based authentication
- Add login and registration endpoints
- Include password hashing with bcrypt

CLI Options

Generate Commands

commi generate

Generate commit message for staged changes

commi generate --copy

Generate and copy to clipboard

commi generate --commit

Generate and commit automatically

Configuration

Set your Gemini API key

commi config get

List all configuration settings

Reset configuration to defaults

Configuration

API Key Setup

First, get your API key from Google AI Studio.

Method 1: Config File (Recommended)

commi config set api-key "your_key"

Method 2: Environment Variable

export COMMI_API_KEY="your_key"

Method 3: Command Flag

commi generate --api-key "your_key"

Available Settings

api-key Your Google AI Studio API key
model AI model (default: gemini-1.5-flash)
max-tokens Maximum tokens per request
validate-format Enable commit message validation

Configuration File

Configuration is stored in ~/.config/commi.toml

[commi-config]
api-key = "your_api_key_here"
model = "gemini-1.5-flash"
max-tokens = 800000
validate-format = true

Usage Examples

Basic Workflow

# Make your changes
git add .
# Generate commit message
commi generate
# Review and commit
git commit -m "feat: add user dashboard"

Quick Commit

# Stage changes and commit in one step
git add .
commi generate --commit
# Automatically commits with generated message

Copy to Clipboard

# Generate and copy message
commi generate --copy
# Then paste in your Git GUI
Ctrl+V in your favorite Git client

Check Repository Status

# See what's changed
commi status
# Verbose output
commi status --verbose

Best Practices

✅ Do

Stage related changes together

Group logically related changes for better commit messages

Review generated messages

Always review and edit AI-generated messages if needed

Use meaningful file names

Clear file names help AI understand the context better

❌ Don't

Commit massive changes at once

Break large changes into smaller, focused commits

Blindly accept all messages

AI can make mistakes - always review the output

Share your API key

Keep your API key private and secure

Advanced Installation

Manual Installation

1. Download Binary

wget https://github.com/Mahmoud-Emad/commi/releases/latest/download/commi-$(uname -s)-$(uname -m)

2. Make Executable

chmod +x commi-*

3. Install

sudo mv commi-* /usr/local/bin/commi

Build from Source

1. Clone Repository

git clone https://github.com/Mahmoud-Emad/commi.git

2. Build

cd commi && ./scripts/build.sh

3. Install Completions

./scripts/install-completions.sh
