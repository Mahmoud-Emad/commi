Why Choose Commi?

Everything you need to start using Commi effectively

Lightning Fast

Built with Rust for maximum performance. Generate commit messages in milliseconds.

AI-Powered

Uses Google's Gemini AI to understand your code changes and generate meaningful messages.

Highly Configurable

Customize message format, AI model, and behavior to match your workflow perfectly.

Secure & Private

Cross-Platform

Works seamlessly on Windows, macOS, and Linux. Single binary, no dependencies.

Command Reference

All the commands you need to use Commi effectively

Generate Commands

commi generate

Generate commit message for staged changes

commi generate --copy

Generate and copy to clipboard

commi generate --commit

Generate and commit automatically

Configuration

commi config set api-key "key"

Set your Gemini API key

commi config get

List all configuration settings

commi config reset

Reset configuration to defaults

Get Started in Seconds

Choose your preferred installation method

Quick Install (Recommended)

One command to install Commi on any Unix-like system:

Terminal
curl -fsSL https://raw.githubusercontent.com/Mahmoud-Emad/commi/main/install.sh | sh

Install via Cargo

If you have Rust installed:

Terminal
cargo install commi

Direct Download

Download the binary for your platform:

Linux x64 macOS Intel macOS Apple Silicon Windows x64

After Installation

  1. Get your Google Gemini API key from Google AI Studio
  2. Set your API key: commi config set api_key YOUR_API_KEY
  3. Navigate to your git repository and run: commi generate --commit
